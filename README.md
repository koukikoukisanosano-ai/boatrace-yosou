# 競艇予想（スマホだけで見られる・GitHubで自動更新）

予想ページ: **https://koukikoukisanosano-ai.github.io/boatrace-yosou/**

iPhone の Safari で開いて「共有」→「ホーム画面に追加」すると、アプリのように開けます。
PC は不要です。データの取り込み・学習・公開はすべて GitHub（Actions と Pages）が自動で行い、
予想の計算はスマホのブラウザの中で行います。

## 予想に使っている情報

- **直前情報（必ず加味）**: スタート展示の進入コースと展示ST、展示タイム、チルト、体重・調整重量、部品交換、新プロペラ
- 気象: 天候・風速・風向・波高・気温・水温
- 出走表: 級別・年齢・体重・F/L・平均ST・全国/当地勝率・モーター/ボート2連率
- 近況（前日までの結果から計算）: コース別の1着率、直近10走、今節の成績、本番STの平均とばらつき、モーターの近況
- レース場×進入コースの1着率、並び（内側・外側の艇との展示ST差、勝率差など）

展示が終わる前のレースは「展示前」と表示し、出走表と近況だけで計算した仮の予想を出します。
直前情報が出ると自動で計算し直して「直前反映」になります（画面は1分ごとに自動更新）。

## 予想のしかた（2026/11/4 に方法を総当たりで比べて決定）

各月のレースを「その月より前のデータだけ」で学習したモデルで予想し直し、開発期間（4〜7月）で方法を選び、
選ぶのに使っていない本番テスト期間（8月〜）で成績を確かめました（ページの「方法の比較」、`docs/data/research.json`）。

- **確率**: 3つのモデルの平均（機械学習／新しい日ほど重く見る機械学習／レース内で6艇を比べる条件付きロジット）。
  10通りの中で開発・本番テストとも一番良かった（本番テスト: 1着の的中 57.1%、3連単 本命10.3%・上位5点34.9%）
- **締切前のオッズ**: 締切7〜2分前に公式サイトから3連単オッズを自動で取り、予想に50%混ぜる（オッズを混ぜると 1着の的中 57.9%）
- **おすすめの買い方**（本番テストでの成績）: 複勝の本命1点（的中76%・回収94%）、単勝の本命1点（本命50%以上のレース・回収92%）、
  3連単の本命1点（本命の確率10%以上のレース・回収87%）、2連単の本命1点（本命30%以上・回収84%）
- 約1.6万通りの買い方を比べても、安定して回収率100%を超える方法は見つかっていません（売上の約25%が差し引かれるため）。
  単勝・複勝などの確定オッズを見て選ぶと回収率200%超えに見えますが、締切直前の大口買いで歪んだオッズを後から選んでいるだけなので除外しています
- 毎週日曜の夜に比較をやり直し、おすすめの買い方を更新します

## 画面の見方

- **色の帯**: 6艇の1着の確率（白=1号艇 黒=2 赤=3 青=4 黄=5 緑=6）。帯が長いほど勝ちそう
- **◎○▲△**: 1着の確率が高い順
- **本命**: 一番確率が高い3連単
- レースをタップすると、各艇の 1着・2連対・3連対 の確率、直前情報、3連単の確率上位、2連単・3連複・2連複、予想の根拠を表示
- **目安◯倍**: 確率から計算したつり合いの倍率。実際のオッズがこれより高ければ、予想どおりなら得な買い目
- **終了・答え合わせ**: その日の結果と、予想が当たったか（1着・3連単上位5点）、上位5点を100円ずつ買った場合の回収率
- **毎日の記録**: 毎朝、前日のレースを「その日の朝の時点のデータとモデル」で予想し直した成績を自動で記録（後から分かった結果は使わない、ずるの無い成績）
- 左上の ‹ › で前の日の答え合わせも見られます

| いつ | 内容 |

| 7:50〜最終レース | 締切20分前からの直前情報、締切7〜2分前の3連単オッズを公式サイトで取り、すぐ公開（数分で反映） |

iPhone からの操作:
- **今すぐ学習し直したい**: GitHub の `boatrace-yosou` →「Actions」→「毎朝の準備…」→「Run workflow」で「学習し直す」に✓
- **動いているか確認**: 「Actions」に緑のチェックが並んでいればOK

## 予想の成績

学習に使っていない直近約2か月のレースで予想し直した結果はページ下部に、毎日の答え合わせ（その日の朝の時点のデータで予想し直した、ずるの無い成績）は「答え合わせ」に表示しています。
**予想だけで儲かるものではありません**（どの買い方も回収率は100%未満）。

## データ

- [Boatrace Open API](https://github.com/boatraceopenapi/api)（非公式・MIT）: 出走表・直前情報・結果・払戻（2026年1月〜）
- BOAT RACE 公式サイトの直前情報ページ（締切前のレースだけ、間隔を空けて取得）
- PC版（boatrace-ai）で集めた 2025年10〜12月の結果（近況の計算の下地）

## しくみ（ファイル）

```
docs/                 公開されるページ
  index.html          画面
  js/core.js          整形・近況・特徴量・モデル・3連単の確率（学習と予想で同じ計算）
  js/app.js           画面の動き
  model/model.json    学習済みモデル（勾配ブースティング木）
  data/state/         その日走る選手の近況
  live/               自動取得した直前情報
tools/
  fetch_openapi.py    過去データの取り込み
  build_dataset.mjs   学習用の表を作る（core.js を使用）
  train.py / train_all.py  学習・書き出し（3つの平均と展示前）
  research.py / research_eval.py  予想方法の総当たり比較
  fetch_odds.py / odds_parse.py   過去の確定オッズ・締切前オッズの読み取り
  evaluate.mjs        過去レースでの答え合わせ（ページと同じ計算）
  make_state.mjs      選手の近況
  live.py             直前情報の自動取得
  report.mjs          毎日の答え合わせの記録
data/openapi/         過去データ（日別）
```

予想は参考情報です。舟券の購入は20歳以上、余裕のある範囲で楽しんでください。

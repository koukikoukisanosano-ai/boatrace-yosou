# 競艇予想（スマホだけで見られる・GitHubで自動更新）

予想ページ: **https://koukikoukisanosano-ai.github.io/boatrace-yosou/**

iPhone の Safari で開いて「共有」→「ホーム画面に追加」すると、アプリのように開けます。
PC は不要です。データの取り込み・学習・公開はすべて GitHub（Actions と Pages）が自動で行い、
予想の計算はスマホのブラウザの中で行います。

## 予想に使っている情報

- **直前情報（必ず加味）**: スタート展示の進入コースと展示ST、展示タイム、チルト、体重・調整重量、部品交換、新プロペラ
- 気象: 天候・風速・風向・波高・気温・水温
- 出走表: 級別・年齢・体重・F/L・平均ST・全国/当地勝率・モーター/ボート2連率
- 近況（前日までの結果から計算）: コース別の1着率、直近10走、今節の成績、本番STの平均とばらつき、モーターの近況
- レース場×進入コースの1着率、並び（内側・外側の艇との展示ST差、勝率差など）

展示が終わる前のレースは「展示前」と表示し、出走表と近況だけで計算した仮の予想を出します。
直前情報が出ると自動で計算し直して「直前反映」になります（画面は1分ごとに自動更新）。

## 予想のしかた（2026/11/5 から: 展開モデル＋展示最重視）

- **展開モデル**: 「誰が・どの決まり手（逃げ・差し・まくり・まくり差し・抜き/恵まれ）で勝つか」→「その展開で誰が2着か」→「3着は誰か」の順に、
  1着艇・2着艇との並び（コースの差）や選手・展示の差＝**選手の組み合わせ**を使って3連単の確率を出します。
  検証（学習に使っていない直近2か月・ページと同じ計算）では、前の「3つの平均」より3連単の確率の当たり具合が良くなりました
  （1着 57.3%、3連単 本命10.3%・上位5点35.0%／前の方法 57.5%・10.3%・34.9%）。決まり手の割合もほぼ実際どおり（逃げ53%・差し12%・まくり15%…）
- **展示最重視（初期設定）**: 展開モデルに「枠（コース）＋展示航走だけのモデル」を重み0.85で混ぜます。
  枠の有利さは残し、それ以外では展示航走（展示タイム・スタート展示・チルト・部品交換など）が一番効く材料になる重さです
  （材料の効き: 展示 7.3 > 選手の力 6.6 > 近況 3.1。混ぜないと 展示 2.6・選手の力 30.1）。
  **代わりに的中率は下がります**（1着 55.3%、3連単 本命7.8%・上位5点29.5%）。画面上の「総合（的中率重視）」に切り替えると混ぜません
- **締切前のオッズ**: 締切7〜2分前に公式サイトから3連単・2連単オッズを自動で取り、予想に混ぜます
- **期待値のある買い目（3連単・2連単）**: 期待値＝確率×オッズ。2026年3〜6月で決め方（期待値の下限・確率の下限・倍率の上限・1レースの点数・オッズを混ぜる割合）を選び、
  7〜10月で確かめました（`docs/data/research_ev.json`、ページの「方法の比較」）。
  - 2連単: 期待値1.35以上・60倍以下・1レース5点まで（展示最重視）→ 本番テスト 回収101%（±8%）・5,625点、総合では 期待値1.1以上・確率2%以上・2点まで → 101%（±6%）
  - 3連単: どの決め方も本番テストで回収80%前後（100%に届かず）
  - ただし検証は**確定オッズ**で計算しています。実際に買う締切前のオッズでは結果がぶれるので、毎日の記録（実際に締切前に取ったオッズで選んだ成績）で確かめていきます
- 選んだ買い目はフォーメーションの書き方（例 `1-3-245`）、点数、当たる確率の合計、期待値で表示します
- 前の比較（3つの平均・約1.6万通りの買い方）は `docs/data/research.json` に残しています。安定して回収率100%を超える方法は見つかっていません

## 画面の見方

- **色の帯**: 6艇の1着の確率（白=1号艇 黒=2 赤=3 青=4 黄=5 緑=6）。帯が長いほど勝ちそう
- **◎○▲△**: 1着の確率が高い順
- **本命**: 一番確率が高い3連単
- **予想の重み**: 「展示最重視」（初期設定）と「総合（的中率重視）」を切り替えられます（スマホに記憶）
- レースをタップすると、各艇の 1着・2連対・3連対 の確率、直前情報、**展示評価**（枠＋展示航走だけで見た1着の確率）、
  **展開の予想**（決まり手ごとの確率と、その展開での2・3着の並び）、**期待値のある買い目**（3連単・2連単）、3連単の確率上位、ほかの券種、予想の根拠を表示
- **目安◯倍**: 確率から計算したつり合いの倍率。実際のオッズがこれより高ければ、予想どおりなら得な買い目
- **終了・答え合わせ**: その日の結果と、予想が当たったか（1着・3連単上位5点）、上位5点を100円ずつ買った場合の回収率
- **毎日の記録**: 毎朝、前日のレースを「その日の朝の時点のデータとモデル」で予想し直した成績を自動で記録（後から分かった結果は使わない、ずるの無い成績）
- 左上の ‹ › で前の日の答え合わせも見られます

## 自動で動くもの（日本時間）

| いつ | 内容 |
|---|---|
| 毎朝 5:40（7:35 にもう一度） | 前日までの結果を取り込み、前日の答え合わせを記録し、今日走る選手の近況を作る。月曜は学習し直し |
| 7:50〜最終レース | 締切20分前からの直前情報、締切7〜2分前の3連単・2連単オッズを公式サイトで取り、すぐ公開（数分で反映） |
| 毎日 12:20 | 前日の確定オッズを取り込む（比較の材料） |
| 毎週日曜 24:07 | 予想方法の比較・展示の重さ・期待値の買い方の比較をやり直す |
| いつでも | ページを開くと、公開データ（約10分おき更新）と自動取得した直前情報を合わせて計算 |

iPhone からの操作:
- **今すぐ学習し直したい**: GitHub の `boatrace-yosou` →「Actions」→「毎朝の準備…」→「Run workflow」で「学習し直す」に✓
- **動いているか確認**: 「Actions」に緑のチェックが並んでいればOK

## 予想の成績

学習に使っていない直近約2か月のレースで予想し直した結果はページ下部に、毎日の答え合わせ（その日の朝の時点のデータで予想し直した、ずるの無い成績）は「答え合わせ」に表示しています。
**予想だけで儲かるものではありません**（どの買い方も回収率は100%未満）。

## データ

- [Boatrace Open API](https://github.com/boatraceopenapi/api)（非公式・MIT）: 出走表・直前情報・結果・払戻（2026年1月〜）
- BOAT RACE 公式サイトの直前情報ページ（締切前のレースだけ、間隔を空けて取得）
- PC版（boatrace-ai）で集めた 2025年10〜12月の結果（近況の計算の下地）

## しくみ（ファイル）

```
docs/                 公開されるページ
  index.html          画面
  js/core.js          整形・近況・特徴量・モデル・3連単の確率（学習と予想で同じ計算）
  js/app.js           画面の動き
  model/model.json    学習済みモデル（勾配ブースティング木）
  data/state/         その日走る選手の近況
  live/               自動取得した直前情報
tools/
  fetch_openapi.py    過去データの取り込み
  build_dataset.mjs   学習用の表を作る（core.js を使用）
  train.py / train_all.py  学習・書き出し（展開モデル・枠＋展示のモデル・展示前）
  tenkai.py           展開モデル（1着×決まり手 → 2着 → 3着）
  tenkai_exhibit.py   展示航走を混ぜる重さと、材料ごとの効き
  research_tenkai.py  展開モデルでの期待値の買い方（3連単・2連単）の比較
  research.py / research_eval.py  予想方法の総当たり比較
  fetch_odds.py / odds_parse.py   過去の確定オッズ・締切前オッズの読み取り
  evaluate.mjs        過去レースでの答え合わせ（ページと同じ計算）
  make_state.mjs      選手の近況
  live.py             直前情報の自動取得
  report.mjs          毎日の答え合わせの記録
data/openapi/         過去データ（日別）
```

予想は参考情報です。舟券の購入は20歳以上、余裕のある範囲で楽しんでください。
